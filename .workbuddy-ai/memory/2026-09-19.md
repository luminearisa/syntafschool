## Temuan penting: `tsc --noEmit` di root frontend adalah no-op

`frontend/tsconfig.json` hanya berisi `files: []` + `references`. Jadi
`npx tsc --noEmit` **tidak memeriksa satu file pun** dan selalu "lulus".
Verifikasi yang benar: `npx tsc -p tsconfig.app.json --noEmit` atau `npm run build` (memakai `tsc -b`).
Begitu dicek dengan benar, ketemu 1 error nyata: `errors` di `StudentAttendancePage` bertipe
`Record<string,string>` padahal `getValidationErrors()` mengembalikan `Record<string,string[]>`.
Sudah diperbaiki.
