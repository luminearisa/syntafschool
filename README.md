# Syntaf School ERP

Sistem ERP (School Management System) untuk **Syntaf School** dengan arsitektur decoupled:

- **Backend:** Laravel 11 (REST API)
- **Frontend:** React JS + TypeScript (Vite)

## Struktur Repository

```
schoolerp/
├── backend/     # Laravel API
├── frontend/    # React + TypeScript
└── docs/        # Dokumentasi & perencanaan
```
